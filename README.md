# BeLIEve

BeLIEve is a 2D Unity puzzle-platformer inspired by games like Level Devil and created by four Rangsit Students for a midterm project. The player takes control of a square navigating through four uniquely challenging levels filled with devious traps and obstacles made entirely of geometric shapes. Your objective is to escape each level by finding and entering the correct portal—but beware, not everything is as it seems!

## Features

- **Minimalist Design:** All traps and obstacles are constructed using simple geometric shapes for a clean, abstract aesthetic.
- **Challenging Gameplay:** Each level introduces new kinds of traps and tricks designed to test your reflexes and problem-solving skills.
- **Multiple Levels:** Four distinct levels, each with its own theme and mechanics.
- **Portal Escape:** The goal is to reach and enter the correct portal to complete each level. Some portals may be misleading!
- **Square Player:** You control a square—movement and interactions are straightforward, but the levels are anything but!

## Gameplay

- Move the square player left, right, and jump using keyboard controls.
- Watch out for traps—some may move, disappear, or behave unpredictably.
- Pay close attention to the layout; only one portal in each level is the correct escape.
- Experiment and learn from each attempt to progress!

## Getting Started

### Prerequisites

- Unity (Recommended version: 2021 or newer)
- A keyboard for controls

### Installation & Play

1. Clone this repository:
   ```bash
   git clone https://github.com/akkminn/beLIEve.git
   ```
2. Open the project in Unity Hub.
3. Press Play in the Unity Editor to start the game.
4. Or build the project for your desired platform (`File > Build Settings`).

## Project Structure

```
Assets/
├── Scenes/                # Contains all level scenes
├── Scripts/               # C# scripts for player, traps, portals, etc.
├── Prefabs/               # Prefabricated objects for geometric traps and portals
├── Art/                   # Geometric shapes and visual assets
└── README.md
```

## Controls

- **A / Left Arrow** — Move left
- **D / Right Arrow** — Move right
- **Space** — Jump
